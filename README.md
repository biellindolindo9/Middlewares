Middleware API

Projeto desenvolvido em sala de aula com orientação do professor para aprender o funcionamento de middlewares no Node.js com Express.

📚 O que foi aprendido

Criação de middlewares
Logs de requisição
Autenticação básica
Tratamento de erros
Organização de rotas e controllers
🛠️ Tecnologias
Node.js
Express.js
JavaScript
▶️ Como executar
git clone https://github.com/biellindolindo9/Middlewares.git
cd Middlewares
npm install
npm run dev
📌 Objetivo

Entender como os middlewares interceptam requisições e controlam o fluxo da aplicação antes da resposta ao cliente.

👨‍🏫 Contexto

Projeto acadêmico realizado em aula para prática de conceitos de backend e APIs REST.
